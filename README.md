**MyTasks** est une application web fullstack dynamique de gestion de tâches. L'application repose sur une architecture moderne complètement découplée : un Single Page Application (SPA) développé avec **React** et **Vite** en frontend, consommant une API REST personnalisée bâtie en **PHP 8 (Architecture MVC)** avec une base de données **MySQL**.

📍 **Démo en ligne :** https://mytasks.alwaysdata.net/
